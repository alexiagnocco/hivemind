# 00-inbox — unprocessed captures

Raw captures land here for triage: meeting scraps, ideas, links, session
handoffs written under pressure. Items **leave** this folder — file them into
the PARA folders during triage (see the placement rules in
[[STRUCTURE]] and `.claude/rules/hive-architecture.md`).

**Stays flat** — no subdirectories. This is a queue, not a home; anything
that needs organizing has already overstayed.

What does **not** belong here: anything you already know the destination of
(file it directly), and system files (`_meta/`).
