# 30-resources — reference material

Reusable patterns, techniques, guides, and how-tos, organized in **one
subdirectory per domain** matching the tag vocabulary: `backend/`, `ai-ml/`,
`synthesis/` (cross-domain connection notes from `/connect`), and new
domains as they earn ≥3 notes. Notes here are project-agnostic — they should
still make sense when the project that spawned them is archived.

What does **not** belong here: project-scoped decisions
(`10-projects/<slug>/` or `memory/projects/`), responsibility-scoped working
notes (`20-areas/`), and untriaged captures (`00-inbox/`).
