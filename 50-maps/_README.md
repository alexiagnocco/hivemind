# 50-maps — maps of content

One MOC per domain or theme (`MOC-Topic-Name.md`), each linking to the notes
it organizes. MOCs are orienting maps for humans browsing the hive; the
retriever consumes their link structure implicitly (connectivity scoring),
so keep them current — every content note should be reachable from at least
one MOC.

**Stays flat** — a dozen MOCs don't need subdirectories. Dashboard MOCs
(like [[50-maps/MOC-Projects|MOC-Projects]]) use serialized Dataview queries
so their tables are readable outside Obsidian.
