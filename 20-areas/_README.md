# 20-areas — ongoing responsibilities

One subdirectory per area of ongoing responsibility — work with a standard
to maintain but no end date: `20-areas/<area>/` (e.g. `reliability/`,
`code-review/`, `on-call/`). Each area folder gets a landing note named
after the area (`20-areas/reliability/reliability.md`, `type: area`).

Cross-area running logs (like `accomplishments-log.md`) may sit at this
level directly.

What does **not** belong here: time-bounded efforts (`10-projects/`) and
reference material you consult but aren't responsible for (`30-resources/`).
